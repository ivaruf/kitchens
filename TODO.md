# Worklist

Things agreed as wanted but not yet built. Newest at the bottom.

- **How the counter is used.** Today it holds what tempts you and suggests
  dishes by key ingredients. What it is *for* beyond that is still to be
  decided.

- **Suggest dishes from ingredient synergies.** Beyond "you have 3 of 4 key
  ingredients": suggestions driven by how ingredients work together. Being
  scoped with the owner one question at a time (2026-10-02); answers so far:
  - *Which synergy:* **dishes that share ingredients**, so one shopping trip
    makes two or three dishes that go together. Not flavour pairings, not
    fridge-clearing, not cross-kitchen fusion.
  - *What a set adds up to:* **both, side by side**: "make a meal of it" (one
    evening: main, side, meze) and "use it up this week" (several days from
    one shop, less waste).
  - *Where a set starts:* **both**: a recipe page offers the dishes that go
    with it, and the counter offers sets built from what is on it.

- **Alternative ingredient suggestions.** Asked for 2026-10-02. To be scoped
  with the owner after the synergy item, one question at a time.

- **Norwegian as a choosable language.** Asked for 2026-10-02.
